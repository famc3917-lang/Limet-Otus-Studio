# Reporting vulnerabilities / 漏洞报告

## English

Please do not report vulnerabilities in public issues. Use GitHub's **Report a vulnerability** button on the repository's **Security** tab to send a private report. Include the affected version, steps to reproduce and the impact you observed.

We will acknowledge the report, investigate and coordinate a fix and disclosure with you. Fixes are provided for the latest released version.

The software is provided as is; see [NOTICE-AS-IS.md](NOTICE-AS-IS.md).

## 中文

请不要在公开的 Issue 中报告漏洞。请在仓库的 **Security** 页面使用 **Report a vulnerability** 私下提交，并写明受影响的版本、复现步骤和观察到的影响。

我们会确认收到报告、进行调查，并与你协调修复和公开的时间。修复针对最新发布的版本提供。

软件按现状提供，见[现状与责任说明](NOTICE-AS-IS.md)。
