# 观隅鸮馆版本更新说明

本软件开发使用了 AI 辅助。

本文件记录各版本面向使用者的变化。首个版本列出全部功能，之后的版本列出新增、改进、修复与移除。

## V3.0.0

观隅鸮馆的首个公开版本，提供 Windows 桌面版与服务器部署模板。

### 工作台与订单

- 工作台汇总订单、未完成的前期与后期工单、付款进度与退款状态。
- 订单记录客户昵称、客户类型、性别、成年情况与监护人同意、拍摄时间与地点、摄影师、套餐、增项、返图安排与备注。
- 按客户类型前缀、日期、性别编码与月内序号自动生成订单编号；前期与后期工单编号分别附加后缀。
- 套餐自动带出价格、返图张数与周期；增项支持固定价格、按数量计价、减免与提前返图。
- 同一天拍摄较多时提示档期负荷。
- 订单经准备、拍摄、后期、交付到完成；确认交付时记录实际交付时间。
- 订单署名绑定成员账户，并保留当时的成员名称。

### 前期与后期

- 前期工单记录拍摄安排、角色、拍摄风格、设备与多张存储卡、预计支出。
- 后期工单记录拍摄张数、精修张数、返图张数与时间，以及所用后期软件；工单按待处理、进行中、已完成推进。
- 设备台账按类别管理，工单保留设备编号快照。

### 拍摄日历与天气

- 月历显示每日场次，可打开日期查看当天订单。
- 城市搜索、逐日天气、风向、降水、紫外线与能见度，并给出外景拍摄建议。天气数据由 Open-Meteo 提供。

### 收款、退款与经营概览

- 分期收款：期数（1–12 期）与每期比例、退款档位（距拍摄日天数与退还比例）均可在「设置 › 订单与付款」中调整；每个订单保存创建时的方案。收款方式、订单来源渠道、客户标签与作品署名均可自行增删。可上传付款与退款凭证。
- 工作室时区默认跟随设备，可在偏好中修改；拍摄时间、时间戳与打印单按工作室时区显示。
- 经营概览记录实际收款、退款、订单支出与团队公用支出。
- 成员分成支持固定金额、百分比与混合方案，比例超过 100% 时可等比压缩；分成快照保留当时规则，之后的收支以差额调整。
- 成员查看本人的经营概览，管理者查看团队汇总。所有金额仅供内部估算，不能作为会计或报税依据。

### 打印与声明

- 预定单、订单确认单与付款汇总，支持打印、下载图片与复制。
- 声明框、富文本、表格与多套模板，实时预览；中文与英文模板分别保存。

### 成员与权限

- 首位账户为超级管理员，其他成员凭一次性邀请代码注册。
- 五种角色与十五个权限点；API 密钥可限定权限与有效期，随时撤销。
- 关键操作写入审计记录。

### AI 助手与语音

- 接入 OpenAI 兼容接口或 Anthropic 接口的模型，支持模型发现、连接测试与联网检索。
- 助手按“挂载能力”使用业务工具；写操作须用户确认；助手最高只有摄影师权限，无法读取客户私人字段。
- 两个化身：隅鸮 Limenotus（男声）与媱鸮 Limenotessa（女声）。
- 语音识别（SenseVoiceSmall）与语音合成（CosyVoice），在软件内安装，回复可自动朗读。

### 超级管理员命令面板

- 在主窗口按 Ctrl + 反引号键唤起，提供中英文固定语法、补全与帮助。
- 覆盖设置、分润、订单、工单、业务目录、经营与系统；写入前预览，输入大写 Y 后在一个事务内执行。

### 资料留存

- 按交付时间计算保留期，到期提醒、稍后提醒、延期申请与审批。
- 清理时删除客户资料与付款凭证截图，只保留脱敏的金额记录。

### 界面与桌面

- 中文与英文界面；界面语言与工作室币种分别管理。
- 深色与浅色主题、减少动态效果；窗口底色随主题同步。
- 桌面托盘、后台运行、全局快捷键与桌面悬浮球。
- 业务备份导出与导入，可配置自己的 Git 仓库备份。
- Windows 安装程序：中英文双语、国际主义平面风格，为当前用户安装、无需管理员权限；附带同风格的卸载程序。另提供免安装的便携版。
- 全部错误与拒绝提示随界面语言显示，并在《错误与提示参考》中逐条说明含义与解决办法。

### 部署与开发

- 服务器部署模板：Docker Compose、PostgreSQL、独立 API 与 Caddy。
- 家族订单引用只读接口（协议 1）。
- 天气服务可在命令面板“天气”模块配置：默认 Open-Meteo 免费接口，可填入商业接口密钥或改用兼容的自建服务；天气请求由服务器转发，密钥不发送到浏览器。
