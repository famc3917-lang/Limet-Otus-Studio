# 观隅家族对接说明

本软件开发使用了 AI 辅助。

## 1. 产品分工

| 产品 | 职责 | 状态 |
| --- | --- | --- |
| 观隅鸮馆 Limet Otus Studio | 订单、档期、前后期工单、成员、收支与交付 | V3.0.0 开发中 |
| 观隅蔵 Limetkura | 图库归档、选片与批量调校，先以 JPG 雏形验证 | 规划中 |
| 观隅庵 Limetan | 像素编辑、图层与创意合成 | 后续规划 |

鸮馆负责业务流程，影像的整理与编辑由观隅蔵和观隅庵承担。这两款产品尚未发布：除第 2 节的只读接口外，本文描述的联动是设计方向，尚未实现。

## 2. 已提供：订单引用只读接口

供后续产品按订单关联影像资料。只开放 GET，需要 `business:read` 权限（会话或 API 密钥）。

请求头 `X-Limet-Family-Protocol` 可选；填写时必须为 `1`，否则返回 426。

### 能力查询

```
GET /api/v1/family/capabilities
```

```json
{
  "family": "Limet Otus",
  "product": "studio",
  "applicationVersion": "3.0.0",
  "protocol": 1,
  "capabilities": ["order.reference.read"],
  "plannedProducts": ["Limetkura", "Limetan"]
}
```

### 订单引用

```
GET /api/v1/family/orders/<订单 ID>
```

订单 ID 由 1–120 位字母、数字、`_`、`-` 组成。资料已按留存规则清理的订单返回 404。

```json
{
  "protocol": 1,
  "reference": {
    "workspaceId": "…",
    "orderId": "…",
    "orderNo": "…",
    "customerName": "…",
    "shootTime": "2026-10-20T10:00",
    "location": "…",
    "stage": "post",
    "flow": null,
    "deliveredAt": null
  }
}
```

引用只包含关联影像所需的字段，不含金额、备注、客户联系方式或付款凭证。

## 3. 关联标识

后续产品应保存 `workspaceId` + `orderId` 作为关联键，`orderNo` 仅用于显示。订单编号可能因业务规则调整，不应作为主键。

## 4. 规划中的联动

以下内容尚未实现，接口与数据格式以后续版本为准：

1. 从鸮馆订单进入观隅蔵时，素材保留订单关联；筛选与调校后的版本回到对应订单。
2. 需要局部精修或合成时，观隅蔵把精选版本交给观隅庵，定稿后回到鸮馆交付。
3. 写入类接口会单独设计版本与权限，不会复用当前只读协议。

## 5. 兼容约定

- 协议号变化表示不兼容的修改；客户端应读取 `capabilities` 并只使用已列出的能力。
- 同一协议号内只会新增字段，不会删除或改变已有字段的含义。
