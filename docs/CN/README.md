# 观隅鸮馆 V3.0.0 文档

本软件开发使用了 AI 辅助。

观隅鸮馆 Limet Otus Studio 是面向个人摄影师与小型工作室的业务管理软件，管理订单、档期、前后期工单、成员、设备、收付款与交付。
