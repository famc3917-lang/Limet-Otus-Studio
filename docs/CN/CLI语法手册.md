# 观隅 CLI 中文语法手册

适用版本：V3.1.1。本文列出当前已实现的全部命令、参数和符号。后续增加命令时，命令目录、软件内帮助和本手册一起更新。

没有终端经验：先读第2节，复制例子执行，再查模块语法。熟悉CMD或PowerShell：先看第1节的概念对照，再查第3节的符号。开发者对接命令面板：阅读第8节的业务规则和第12节的接口协议。

## 1. 入口与终端概念对照

观隅 CLI 是工作室业务的命令面板。用超级管理员账户登录，在主窗口按 Ctrl + ` 打开命令面板；同一个账户同时使用 GUI 和 CLI，不需要另一套密码。普通账户和 API Key 不能进入命令接口。

|你熟悉的操作|观隅中的对应操作|说明|
|---|---|---|
|`Get-Help` / `help`|`帮助`|查看当前模块语法|
|`Get-Help 模块`|`帮助 模块`|查看指定业务模块|
|`Import-Module`|`引入 模块`|切换业务命令命名空间|
|`exit`|`退出`|退出当前模块，回到通用命令区|
|`Clear-Host` / `cls`|`清屏`|清空面板显示，不清除操作审计|
|查看可用模块|`模块`|列出全部业务模块|
|确认执行|`确认 Y`|执行已经预览的写入方案|
|放弃执行|`取消`|撤销待确认方案|
|请模型准备命令|`AI 需求`|调用软件内配置的模型起草命令|

英文界面使用 `Help`、`Import Settings`、`Set Mode Team` 等固定命令，完整目录见英文语法手册。中文指令组继续有效。CMD、PowerShell 的原生命令名不是别名，例如 `Import-Module` 仍不属于业务语法。语言切换不会翻译订单编号、查询文字或脚本。

输入框支持中文输入法。正在选择候选字时，Enter 只结束输入法组合，不提交命令。补全列表打开时，Enter 或 Tab 先接受补全；再次 Enter 才提交。Shift + Enter 换行，可提交固定指令组。上下方向键选择补全，Escape 关闭补全。

## 2. 最短完整例子

```text
引入 设置
查看
设定 模式 团队
```

前两条立即给出结果。第三条显示拟修改的规则；检查无误，再单独提交：

```text
确认 Y
```

`Y` 必须大写。不准备执行，提交 `取消`。方案五分钟内有效；期间规则被别人修改时，需要重新提交、重新核对。

写入不能靠一次 Enter 连带确认。AI 的草稿也走相同流程，模型不能代替你确认。一次指令组最多50条；分成计算命令单独提交。

## 3. 固定语法和标点

命令结构：`命令 参数1 参数2 …`。参数按位置解释，没有自然语言解析，没有可随意省略的参数名。

|写法或符号|在命令输入框中的含义|
|---|---|
|空格|分隔命令和参数；连续空格不产生空参数|
|换行|同一指令组的下一条固定命令|
|`"…"`|双引号包含一个参数，可保留路径中的空格|
|`'…'`|单引号包含一个参数，作用与双引号相同|
|`.`|金额的小数点；最多两位小数|
|`-`|编号或路径中的普通字符；不是业务参数前缀|
|`:`、`\`、`/`|路径或编号中的普通字符；不会因此执行系统命令|
|`_`|编号或脚本标识符中的普通字符|
|`,`|命令中是普通字符，不用于分隔多个参数|
|`%`|命令参数不能写百分号；50%写作 `50`|
|`--`、`=`|不用于业务参数；不能写 `--金额` 或 `金额=100`|
|中文逗号、冒号、句号|不是语法分隔符；不能用来替代空格或给命令加结尾标点|
|`;`|命令输入框不支持分号拼接；指令组用换行|
|`|`|当前业务命令不支持对象管道|
|`>`、`>>`、`<`|当前业务命令不支持文件重定向|
|`&`、`&&`、`||`|当前业务命令不支持串联执行或后台执行|
|`$变量`、`$(…)`、反引号|当前业务命令不做变量展开、命令替换或转义|
|`()`、`[]`、`{}`|命令输入框不解释表达式；业务脚本中的用法见第8节|
|`#`、`//`|命令输入框不支持注释；业务脚本可以使用JS/TS注释|

引号必须成对。引号内不能再用相同引号作转义；可换用另一种引号。

符号保持原有形态，按所在语言解释；中文化的是业务命令和参数说明。这不意味着把 Windows PowerShell 的所有执行能力移入观隅。上表中尚未支持的操作不会转交系统终端执行。

## 5. 设置模块：全部字段

```text
引入 设置
查看
```

`查看` 没有参数。`设定` 后必须带字段和值，固定为两个参数。

|完整语法|取值|默认值|
|---|---|---|
|`设定 模式 个人`|`个人` / `团队`|个人|
|`设定 保留月数 3`|整数1–120|3|
|`设定 清理宽限月数 1`|整数1–24|1|
|`设定 自动清理 开`|`开` / `关`|开|
|`设定 起算 交付`|`交付` / `拍摄` / `创建`|交付|
|`设定 提权分钟 15`|整数1–120|15|
|`设定 延期审批提权 开`|`开` / `关`|开|

V3.0.0 已接通留存后台任务。降低保留期限或改起算方式可能让旧订单立即到期，请先核对“查看”的规则与订单，再确认方案。关闭自动清理后不再新增自动任务；已确认清理的文件队列继续执行。延期审批提权只授予临时审批能力，不改变角色，不开放CLI。具体范围见隐私保留与延期接口。

个人模式不要求第二名成员；影像审片由观隅蔵负责，观隅鸮馆只保留订单交付确认。

## 6. 分润模块：全部7项

首先 `引入 分润`。下表中的“订单编号”可用订单显示编号，也可用内部订单ID。“账户编号”是成员的稳定ID，不是昵称；可在系统模块查询。

|语法|参数数量|含义|
|---|---|---|
|`查看 订单编号`|1|查看规则与历史分成快照|
|`预留 订单编号 金额 百分比`|3|配置工作室先保留的金额和比例|
|`成员 订单编号 账户编号 固定金额 百分比`|4|新增或替换一个成员在本单的分成|
|`移除成员 订单编号 账户编号`|2|移除尚未产生快照的成员规则|
|`等比压缩 订单编号 开`|2|开启超额比例的等比压缩；关闭写 `关`|
|`计算 订单编号`|1|依据实际到账和支出生成分成快照|
|`导入规则 订单编号`|1|导入面板“业务规则脚本”草稿|

金额单位是元，不能有负数、货币符号或千位逗号；最多两位小数。比例范围0–100，最多两位小数，不附加 `%`。

下面是示意编号，需要换成你自己的订单和账户编号：

```text
引入 分润
预留 C2610072-001 200 10
成员 C2610072-001 0 0 50
成员 C2610072-001 成员账户编号 100 20
```

提交后核对整个方案，再输入 `确认 Y`。新增收款和支出在 GUI 记账；CLI 中单独提交 `计算 C2610072-001` 并确认，生成快照。

计算顺序：实际到账减退款、减本单实际支出；再扣工作室保留；成员固定金额优先，再从共同剩余池按比例分配。各比例针对同一个池，不按成员顺序递减。未分配部分保留在工作室；共同租金、水电单独记录，避免重复扣本单成本。

比例合计超过100%且未开启压缩时会报错。开启压缩后保留相对权重。固定金额超过可分配额时，不悄悄减少承诺金额，需要先处理资金缺口。计算只是账面记录，不发起外部付款。

本单已有历史快照后，CLI不能改写它的规则；新规则用于尚未计算的订单。后续收退款使用原规则计算变动流水，不覆盖旧快照。

## 8. JS / TS业务规则：字段、语法和全部符号

在面板展开“语法参考与业务规则”，把函数粘贴进业务脚本框，然后提交 `导入规则 订单编号`。

```typescript
function 规则(输入) {
  const 保留比例 = 输入.availableCents >= 200000 ? 1500 : 1000;
  return {
    reservePoints: 保留比例,
    member0Points: 5000
  };
}
```

只支持一个同步普通函数、一个参数、数值业务输入。函数名和参数名可以用中文；示例中的字段名是固定的数据协议，不能翻译或猜写。

### 输入字段

|字段|含义|单位|
|---|---|---|
|`receiptsCents`|本单累计实际到账|分|
|`refundsCents`|本单累计退款|分|
|`expensesCents`|本单累计实际支出|分|
|`availableCents`|到账减退款减支出，可为负数|分|
|`reserveCents`|规则中的工作室固定保留额|分|
|`reservePoints`|规则中的工作室保留比例|万分比|
|`member0FixedCents`…`member19FixedCents`|已配置成员按规则顺序的固定金额|分|
|`member0Points`…`member19Points`|同一顺序成员的比例|万分比|

成员字段只为当前规则中实际存在的成员提供；不存在的编号会报错。顺序以 `分润 查看` 中的成员列表为准。

### 返回字段

可返回 `reserveCents`、`reservePoints`，以及当前已配置成员的 `memberNFixedCents`、`memberNPoints`。省略的字段保持原规则值。字段必须是不重复的、非负、可精确表示的整数；比例仍受0–10000限制，人数最多20人。不能返回账户、认证、审计、文件路径、隐私策略或任意其他字段。

`10000` 是100%；`5000` 是50%；`100` 最小货币单位对应1个主货币单位（人民币为100分对应1元）。脚本金额与命令行金额的单位不同。

### 支持的词和语法

|词或写法|作用|
|---|---|
|`function`|声明唯一业务函数|
|`const`|声明唯一命名的局部常量，不允许重复命名或覆盖输入|
|`if` / `else`|根据数值或布尔条件选择分支|
|`return`|返回数值字段对象|
|`true` / `false`|布尔字面值|
|`Math.min` / `Math.max`|最小值 / 最大值|
|`Math.round` / `Math.floor` / `Math.ceil`|四舍五入 / 向下取整 / 向上取整|
|`Math.abs`|绝对值|
|`as`、参数与返回类型标注|TS静态标注；不增加运行权限|
|`export function`|允许函数带export声明，不执行模块导入|

|符号|业务脚本中的含义|
|---|---|
|`()`|函数参数、函数调用或表达式分组|
|`{}`|函数体、条件代码块、返回对象|
|`,`|分隔返回字段或数学函数参数|
|`:`|返回字段和值的分隔符，或TS类型标注|
|`;`|语句结尾|
|`.`|读取固定输入字段、调用允许的Math函数|
|`=`|只用于const变量初始化|
|`+`、`-`|加减，或数值的正负号|
|`*`、`/`、`%`|乘、除、取余|
|`<`、`<=`、`>`、`>=`|数值比较|
|`===`、`!==`|严格相等、不相等|
|`&&`、`||`、`!`|条件逻辑与、或、非|
|`? :`|条件选择表达式|
|`//`、`/* … */`|JS/TS注释|

不支持循环、递归、赋值修改、函数嵌套、异步、生成器、字符串业务字段、数组访问、动态属性、导入、文件、网络和系统调用。`eval`、`new`、`process`、`require`、`fetch`、`globalThis`、`constructor`等没有运行环境。脚本由语法树解释器计算，不直接执行JS。

脚本最大20000字符，一次计算最多3000个解释步骤，每次数学函数最多20个参数。输出仍经过普通分成规则校验；超限、除零产生非有限结果、未知字段或资金不足会阻止生成快照。

## 9. 四空格的原生语法区域

行首四个普通半角空格用于标记原生解释器语法。外层四空格不替代代码自身的缩进；原生代码也不翻译成中文。

```text
    原生解释器原文
```

当前开发版未注册原生维护插件，提交这样的行会明确报错，不会执行Windows命令。未来的处理器只能由软件维护插件提供、限定软件或插件的操作范围；真正需要操作系统提权时再触发UAC。不能借这一区域绕过登录、审计和客户隐私保护。

## 10. AI起草与确认

可以输入 `AI 帮我写出查询订单和查看分润规则的命令`，或使用面板下方“请AI起草”。调用的是软件内已配置模型。AI草稿可能包含解释文字，应检查、删去不属于固定语法的内容，再提交。

模型不会获得CLI执行权，也不会获得超级管理员身份。请求中的已知电话、即时通讯账号和敏感备注会脱敏；不要把密钥或敏感客户资料写在需求里。语音与AI对话中的权限仍以摄影师能力上限处理，不能借CLI页面扩大。

## 11. 界面、字段和常见错误

左上红色按钮关闭面板；黄色收起；绿色扩大或还原。面板使用比工作区更深的墨绿色。显示记录最多保留最近150项，这个限制不删除服务端审计。

|提示|处理方式|
|---|---|
|命令不属于当前模块或语法不符|先 `帮助`，必要时 `引入 模块`|
|参数数量不符|按完整语法补齐参数，不加多余标点|
|引号未闭合|补齐成对的ASCII引号|
|订单不存在|用订单显示编号或内部ID，不用客户昵称替代|
|账户编号不存在|`引入 系统` → `账户`，复制稳定ID|
|方案已过期 / 规则已变化|重新提交、重新预览、重新确认|
|本单已有分成快照|保留历史；在尚未计算的订单设置新规则|
|分成比例超过100%|调整比例，或明确开启等比压缩|
|固定分成超过可分配金额|核对到账、退款与支出，处理缺口后再计算|
|原生解释器没有匹配处理器|当前未接通该维护插件，不会自动运行系统终端|
|命令面板仅供超级管理员使用|使用工作室超级管理员登录会话；API Key也不能使用|

设置查询中的协议字段对照：`mode`个人/团队模式；`retentionMonths`保留月数；`graceMonths`清理宽限月数；`retentionStart`起算方式；`autoDelete`自动清理；`elevationMinutes`提权有效分钟；`elevationScopes`提权范围。分润规则中的 `members` 是成员列表，`fixedCents` 是固定分数，`points` 是万分比，`normalize` 是等比压缩，`script` 是业务函数。`id`是稳定记录编号，`version`是规则版本，`revision`是并发版本；这些不是需要自己猜写的命令参数。

## 12. 开发接口

命令入口：`POST /api/v1/cli`。必须使用超级管理员会话和CSRF令牌；不接受Bearer API Key。服务端每分钟最多60次调用。

|action|字段|用途|
|---|---|---|
|`catalog`|无|读取模块和帮助目录|
|`command`|`module`、`text`，可选`rule`|解释命令；写入返回proposal|
|`confirm`|`id`、`answer: "Y"`|确认当前方案|
|`cancel`|无|取消当前用户的方案|
|`ai`|`module`、`text`|请求配置模型起草，不执行|

`command.text`最多20000字符；每条命令最多2000字符。HTTP JSON上限64000字节。CLI界面与API都不能替代服务端权限检查。手册入口 `/api/v1/cli/manual` 同样要求超级管理员登录；加 `?download=1` 下载Markdown原文。

## 13. V3.0.0 业务命令补充

模块目录：设置、分润、订单、工单、目录、经营、系统、天气。使用 `引入 模块` 切换；英文分别是 Settings、Shares、Orders、Workflow、Catalog、Operations、System、Weather。

订单新增固定字段对语法。字段名与字段值之间用空格，字段值含空格时使用 ASCII 引号。不接受重复字段，不推测缺失的客户资料。

```text
引入 目录
查看 客户类型
查看 套餐
引入 订单
创建 客户 "客户姓名" 类型 TYPE-ID 拍摄 2026-10-20T09:30 性别 女 成年 成年 套餐 PACKAGE-ID 地点 "拍摄地点"
```

创建字段：客户、类型、拍摄、性别、成年为必填；套餐、地点、摄影师、署名、渠道为选填。性别只能是男、女、非二元；成年状态只能是成年、未成年。署名使用系统账户查询返回的稳定账户编号。每次写入单独输入 `确认 Y`。

多个写入可以组成不超过50条的指令组。预览完整执行后回滚；确认时重新检查工作室规则、分成规则和业务版本，并在同一事务中执行。任何一项失败时整组回滚，旧分成快照保持原样。AI 只起草命令；必要客户资料需由操作者填入，不从模型推断。

## 14. 天气服务

日历与 AI 助手使用的天气数据来自与 Open-Meteo 接口格式兼容的服务。默认使用 Open-Meteo 的免费接口，不需要配置。天气请求都由工作室服务器转发，密钥只保存在服务器上（加密存储），浏览器和成员看不到。

**授权提醒：** Open-Meteo 的免费接口仅限非商业用途。商业使用请自行确认 Open-Meteo 的条款，必要时购买其商业接口并在此填入密钥，或改用自建的 Open-Meteo 服务（开源，可部署在自己的服务器上）。

|命令|作用|
|---|---|
|查看|显示当前方式（免费 / 商业 / 自定义）、各接口地址；密钥只显示前后四位|
|密钥 密钥文本|设置 Open-Meteo 商业接口密钥；设置后预报、空气、城市三个接口自动改用 `customer-` 前缀的商业地址，并在请求中附带 `apikey` 参数|
|地址 预报\|空气\|城市 网址|把某个接口改为自定义地址，例如自建的 Open-Meteo；只填接口本身，不要在网址里写密钥|
|恢复默认|清除密钥和自定义地址，回到免费接口|

```text
引入 天气
查看
密钥 你的商业接口密钥
确认 Y
地址 预报 https://weather.example.com/v1/forecast
确认 Y
```

规则：

- 自定义地址必须是兼容 Open-Meteo 的接口：预报接口对应 `/v1/forecast`，空气接口对应 `/v1/air-quality`，城市接口对应 `/v1/search`，参数与返回格式相同。不同格式的天气服务无法直接接入。
- 地址必须使用 HTTPS，并且不能指向内网或保留地址。确需使用局域网内的自建服务时，由部署负责人在服务器环境变量 `STUDIO_WEATHER_ALLOWED_HOSTS` 中列出允许的主机名（逗号分隔），这些主机可以使用 HTTP 或内网地址。
- 每次修改都先预览，输入 `确认 Y` 后生效，并写入审计日志（只记录操作类型，不记录密钥）。
