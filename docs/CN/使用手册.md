# 观隅鸮馆 · V3.0.0 使用手册

本软件开发使用了 AI 辅助。

观隅鸮馆 Limet Otus Studio 用于摄影工作室的订单、档期、工单、人员、设备与交付管理，专为个人或超小型摄影工作室设计，尤其面向泛 ACGN 文化（二次元）摄影；一般的小型、超小型工作室或个人摄影师同样可以使用。本手册对应 V3.0.0。

软件按现有形式提供。数据安全、金额计算的准确性与完整性均不作保证。使用前阅读根目录的[现状与责任说明](../../NOTICE-AS-IS.md)，并自行核对实际业务与备份。

## 1. 创建工作室与登录

首次打开，选择“创建工作室”，填写账户名、网名和密码，选择中文或英文，以及工作室币种。首位账户编号为 0，是超级管理员，无需邀请码。之后新增成员，由工作室管理者发放邀请代码，成员在注册页使用代码注册。服务器部署的首次开通信息由部署负责人提供；软件没有公开默认密码。

密码区分大小写。登录前确认所进入的工作室，结束共享电脑上的工作后退出账户。登录失败时先检查账户、密码和工作室地址，再联系管理者处理。

## 2. 工作空间与偏好

左侧导航进入订单、拍摄日历、前期、后期、经营概览、业务配置和工作室偏好；无权限的入口不会显示。窗口左上角的红、黄、绿按钮分别关闭、最小化和最大化或还原窗口；桌面功能只在支持的客户端中出现。

在工作室偏好中选择深浅主题、中英文界面、减少动态效果、音色和悬浮球。语言选择保存在当前设备。自定义工作室名称、客户姓名、备注、历史对话及已编辑条款保留原文。

工作室时区默认跟随设备，可在偏好的“时区”中修改（例如 Europe/Zurich）。拍摄时间、时间戳与打印单按工作室时区显示，时间戳同时记录 UTC。

界面语言与工作室币种分别管理。记账币种在创建工作室时从常用币种（人民币、美元、欧元、英镑、日元等）中选择；切换界面语言不会换算金额，也不会更改币种标记。有业务记录后，不要通过直接修改数据库改变原有金额的币种。

## 3. 从创建订单到交付

1. 在订单页面选择“创建订单”，填写客户昵称、客户类型、套餐、时间、地点与摄影师，核对后提交。
2. 创建前期工单，记录拍摄安排，选择设备与所需的多张存储卡。拍摄完成后，将前期工单标记为已完成。
3. 创建后期工单，记录修图数量、所用软件与返图计划。后期完成后，订单进入等待交付。
4. 确认作品已交给客户后，在订单详情选择“确认交付”。实际交付时间将被记录，并作为默认资料保留期限的起点。

在业务配置的“订单与付款”中维护作品署名、订单来源渠道、客户标签、收款方式、分期方案（1–12 期，各期比例合计 100%）与退款档位（距拍摄日天数与退还比例，须包含从 0 天开始的一档）。每个订单在创建时保存当时的分期与退款方案，之后修改设置只影响新订单。按约定退款以已收款项乘以适用比例，并扣除前期工单记录的预计支出；“全额退款”退还全部已收款项。

订单署名可以关联成员账户；历史署名保留当时的成员名称。不要将助手的自然语言回复当作执行成功：应确认软件回执与订单记录已经更新。

鸮馆负责从预约到交付的业务流程。照片的整理、选片与调色由规划中的观隅蔵 Limetkura 承担，像素编辑由规划中的观隅庵 Limetan 承担；这两款产品尚未发布。

## 4. 日历与天气

拍摄日历显示每日场次。选择城市时核对行政区域，再打开具体日期查看订单、温度与拍摄建议。预报范围之外的日期不代表天气已确定；天气数据、建议与动画均不能替代现场判断。

城市与天气数据默认由 Open-Meteo 的免费接口提供，经工作室服务器转发，需要服务器能访问该服务。Open-Meteo 的免费接口仅限非商业用途；商业使用请自行确认其条款，必要时由超级管理员在命令面板的“天气”模块填入商业接口密钥或改用自建服务，见[CLI 语法手册](CLI语法手册.md)第 14 节。外景拍摄前复核降雨、风力和高温，按实际情况准备防水用品、配重和饮水。

## 5. 经营概览、到账与分成

经营概览记录实际到账、退款与订单支出，按配置生成成员份额。支持固定金额、百分比与混合方案。软件只进行内部计算，不会向银行或支付平台转账。普通成员查看权限允许的记录；管理者查看团队汇总。

先录入实际收支，再核对分成。比例超过可分配范围时，由管理者选择调整或等比压缩。已形成的历史快照保留当时规则，不随新规则重算。

历史付款阶段参考页按订单已付期数估算收款，并使用前期工单预计支出。它与实际到账流水不同，不得混用。所有金额、结余和分成均可能不准确，不能作为会计记账、纳税申报或法定财务凭证；请独立核对原始凭证。

## 6. 打印单、声明与模板

在工作室偏好中进入“声明与打印模板”，编辑预定单标题、声明方框、文字、表格和样式，核对实时预览后保存。订单详情提供确认单和付款汇总的预览、打印、图片下载与复制。

模板中的 {{付款方案}} 与 {{退款规则}} 会在打印时替换为按当前设置生成的表格。

中文与英文模板分别保存。英文首次使用加载英文默认内容；原有中文模板继续保留。切换语言不会翻译已保存的自定义条款。同一页面内草稿按语言保留，离开页面前先保存。“恢复原文”只重置当前语言模板，保存后生效。打印金额继续使用工作室币种。

条款是可编辑模板，不是法律意见；调整打印条款不会改变已记录的实际收退款。向客户发送前核对所有文字、金额与历史约定。打印保存为 PDF 依赖系统打印服务；复制图片失败时，可下载图片后手动发送。

## 7. AI 与语音

在工作室偏好中选择服务商、模型和接口地址，填写自己的 API Key，测试连接后启用需要的能力。连接失败时核对地址、模型标识、服务商额度与服务状态，不要将密钥发到聊天中。

助手使用软件提供的已授权工具。查询结果只用于当前业务；修改由用户确认。客户的敏感资料不作为助手的订单查询内容。显示连接正常不代表每一项外部服务均可使用。

男声音色对应隅鸮 Limenotus，女声音色对应媱鸮 Limenotessa；音色切换在设置中进行。助手输出可自动朗读，静音只控制播放。界面语言不会自行更换音色；历史对话保留原文。

语音识别和语音合成需要先在助手面板安装：分别选择“安装语音识别”和“安装语音”，软件会联网下载模型并逐个校验文件，界面显示安装进度。只有有 AI 配置权限的账户能安装；其他成员会看到“语音识别待开通”。语音合成模型约 1.7 GB，安装需要较长时间，建议在网络稳定时进行；配置要求见[部署手册](部署手册.md)。

## 8. 超级管理员命令面板

在主窗口按 Ctrl + 反引号键（通常位于数字 1 左侧）唤起命令面板，按 Esc 关闭。其他角色不能进入。中文界面输入“帮助”，英文界面输入“Help”。命令和模块名区分大小写；标识符、金额、查询文字与脚本内容保持原样。

中文示例：先输入“引入 分润”，再输入“帮助”。英文对应“Import Shares”和“Help”。使用固定语法，不能把自然语言直接当作命令。AI 可以起草命令，写入仍须本人检查并输入大写 Y 确认。

完整命令、参数、引号与脚本约定见[CLI 语法手册](CLI语法手册.md)。该面板管理鸮馆业务，不作为操作系统通用终端。

## 9. 资料留存与延期

默认从交付开始计算期限，到期先提醒，宽限期届满后按配置清理。成员可申请延期，有审批权限的账户处理申请。清理会删除该订单的客户资料与付款凭证截图，金额以脱敏记录保留。外部备份和其他软件中的副本需要另行管理。

清理、恢复备份或升级前，核对需要保留的资料。不能把界面提醒视为外部副本已经清理，也不能把软件文档视为数据安全保证。

## 10. 桌面业务备份与故障处理

遇到错误提示时，可在[《错误与提示参考》](错误与提示参考.md)中按提示文字查找含义与解决办法。

在工作室偏好中配置自己的 Git 仓库地址，再在业务配置的数据管理页运行备份。备份订单数据、付款与退款凭证；付款汇总可以单独上传。同一页面的“备份与恢复”可导出业务备份文件（JSON），用于更换电脑或恢复数据；备份文件不包含成员账户和接口密钥。

Git 初始化、暂存或提交失败时停止备份。推送失败后，先核对仓库权限和连接再重试。备份文件不等于完整服务器迁移包；按照[部署手册](部署手册.md)保留所需服务资料，并验证恢复步骤。

保存失败时保留当前输入并处理同步提示。不要反复覆盖发生冲突的记录。服务不可用时请部署负责人查看运行日志；日常使用不要直接修改数据库或安装目录。

### 桌面与软件内助手

桌面悬浮球点击后在桌面展开对话，关闭后收回悬浮球，不要求打开主窗口。软件内悬浮球只移动软件内面板。两个悬浮球互不传递位置；拖动对话标题与拖动其悬浮球作用于同一组界面。桌面助手的服务设置入口会打开主窗口设置页。
