# 灯光测试算法说明（实验性功能）

本文说明“灯光测试”页面每个读数的算法：公式、出处、假设、非实测参数，以及交叉验证。

| 内容 | 文件 |
| --- | --- |
| 曝光、灯具参数、附件、面光源、色度、景深公式 | `src/lib/lighting.ts` |
| 场景、测光、遮挡、棚内反射、景深渲染 | `src/lib/lighting-lab.ts` |
| 交叉验证 | `tests/lighting-physics.cjs`（`npm run test:lighting`，已接入 `npm run check`） |

**适用范围**：解释距离、功率、附件尺寸、角度和光色变化的趋势，用于布光预演。读数不能当作具体灯具实拍曝光的保证；高速同步、近场复杂遮挡、相机 RAW 溢出和肤色还原尚未经过实物验证（见第 13 节）。

## 1. 曝光基准：球形入射测光表

页面模拟的是带乳白球的入射式测光表。依据 ISO 2720 的入射测光方程：

  N² / t = E · S / C

球形受光器取 **C = 340**（世光 Lumisphere 的标定值；平面受光片为 250）。两边乘以 t，得到在 ISO S 下用光圈 N 拍出中灰所需的照度曝光量：

  **H = C · N² / S**（lx·s）

- 由照度曝光量求测光表读数：N = √(H · S / C)。
- 显示方式与测光表相同：整档光圈加十分之一档。

同样 160 lx·s、ISO 100，平面受光片读 f/8，球形受光器读 f/6.86，相差 log₂(340/250) ≈ 0.44 档。

## 2. 闪光指数与持续光

闪光指数的定义：ISO 100 下，距离 d 处正确曝光的光圈为 N = GN / d。代入第 1 节公式，点光源在距离 d 处 H = Q / d²，所以：

  **Q = (C / 100) · GN²**（cd·s）

GN 与测光读数用同一个 C，轴上单灯时 N = GN / d 始终成立。

- GN 必须对应具体灯头和附件。同一机身换灯头或变焦位置，GN 不同；在设备台账填写时应采用标准罩下的值。
- 没有官方 GN 时，按储能估算：GN ≈ 3.5·√Ws。这只是估计。
- 输出档位：p = 2^档位，满光为 1，最低 1/256。
- 附件损失：乘以 2^(−损失档数)，损失是相对标准罩的**轴向强度**变化（见第 3.3 节）。
- **高速同步**：快门快于 1/250 s 时，Q 乘以 (t / (1/250)) × 0.25。系数 0.25 对应约 2 档损失，依据保富图官方说明“高速同步通常比普通闪光少 2–3 档”。这是估计，不是某台灯和某台相机组合的实测曲线；1/250 s 也只是常见同步速度，各机型不同。
- **持续光（LED）**：Q = I · p · 2^(−损失) · t。I 取远场轴向强度，在设备台账中以“1 米照度”填写。厂商公布了多个距离的照度时，宜用 3 m 或 5 m 的值乘以距离平方换算，因为 1 m 处常处于近场，直接按平方反比外推会偏高。
- LED 的调光百分比在这里按线性光输出处理。实际灯具有多种调光曲线，面板百分比不一定等于光输出比例。

**参数来源**：灯具参数全部来自工作室在设备台账中的录入。附件损失和光束角是同类附件的常见值，不是具体产品实测（见第 12 节）。

## 3. 直射光

到达脸部（测光点）的直射照度曝光量，按灯前附件分两类计算。

### 3.1 标准罩、裸灯、束光筒、蜂窝、深抛物面：点光源

  H = Q · f(θ) · D · V / d²

- d：发光点到脸部的距离（下限 0.2 m）。
- f(θ)：光束分布。θ 为偏离光轴的角度，半角 θ½ = 光束角 / 2，x = θ / θ½：f = cos(min(π/2, x·π/3.2))，x ≤ 0 时为 1。光束角边缘处约 0.56，超过 1.6 倍半角为 0。这是平滑近似，不是实测配光曲线。
- D：测光球方向响应（第 4 节）。V：遮挡（第 5 节）。
- 适用条件：距离大于发光口尺寸的 5 倍。理想圆盘在 5 倍直径处，平方反比误差为 1%；带反光或聚光结构的灯具不保证这一界限。

### 3.2 柔光箱、八角罩、柔光伞、雷达罩：均匀 Lambert 面光源

把附件出光面当作亮度均匀的 Lambert 面，法线方向强度等于 I₀（已含附件损失），所以时间积分亮度为：

  **L = Q / A**（cd·s/m²，A 为出光面面积）

几何部分用 Lambert 多边形公式求接收面的投影立体角：

  **Ω⊥ = ½ · Σᵢ θᵢ · (n · γᵢ)**

- vᵢ 为相对接收点的顶点向量；θᵢ 是相邻顶点方向的夹角；γᵢ = (vᵢ × vᵢ₊₁)/|vᵢ × vᵢ₊₁|。
- 计算前用 Sutherland–Hodgman 法把多边形裁剪到接收面的正半空间。
- 接收面法线 n 指向发光面中心。脸部在发光面背后时，直射为 0。
- 出光面形状：矩形（柔光箱、条形箱），正八边形（八角罩，外接圆直径等于标称直径），24 边形近似圆（柔光伞、雷达罩）。

在均匀 Lambert 面这个前提下，公式在任意距离都精确；远场时 Ω⊥ → A·cosθₑ·cosθᵣ/d²，与点光源模型衔接。近距离时两者差别明显，例如直径 0.9 m 的圆盘在轴上 0.6 m 处，点光源模型比面光源高 1.56 倍（0.64 档）。

**测光球响应与遮挡在发光面上积分**：

  **H = L · Ω⊥ · Σ(wᵢ · Dᵢ / cosθᵣ,ᵢ · Vᵢ) / Σ wᵢ**，wᵢ = cosθₑ,ᵢ · cosθᵣ,ᵢ / rᵢ²

在出光面上取 8×8 个采样点（圆形和八边形附件只取轮廓内的点），每点单独计算测光球响应 Dᵢ 和遮挡 Vᵢ。几何总量仍由 Lambert 公式精确给出，采样只负责按光的实际来向加权。这样挡住发光面中心和挡住边缘，得到的光量不同。

**已知简化**：真实柔光箱中心比边缘亮；雷达罩比漫射面更聚光；带蜂窝的柔光箱不是 Lambert 分布，所以没有提供“柔光箱 + 蜂窝”。

**出处**：Lambert（1760）多边形光源照度公式；Arvo（1994）向量照度形式；Stark（2000）顶点形式。

### 3.3 附件损失的含义

损失档数表示相对标准罩的轴向强度变化，不表示总光通量透过率。换成 Lambert 面后，总光通量由 Φ = π·Q 决定，可能和点光源配光下的总光通量不同。有些附件（如深抛物面、保富图 OCF Magnum）会提高轴向强度，所以损失可以很小。

## 4. 测光球方向响应 D

乳白球在光从正前方来时响应最大，从侧面来约一半，从背后来为 0：

  **D = (1 + cos α) / 2**

α 是光到达方向与测光球朝向的夹角，测光球朝向拍摄机位。这是近似，实际测光球的响应因型号而异，需要用实物测光表做正面和侧面标定。

## 5. 遮挡 V

从发光点向脸部发射射线，检测人物和道具是否挡住。点光源 1 条射线；面光源在第 3.2 节的 64 个采样点上各 1 条。射线终点前留 min(0.12 m, 0.1 × 距离) 的余量，避免打到脸部自身。

## 6. 棚内反射（反弹补光）

把整个影棚当作积分腔：

  **H_反射 = 2 · Φ · ρ₁ / (A_总 · (1 − ρ̄))**（lx·s）

- Φ：所有灯一次曝光内的光通量积分。点光源 Φ = 2π ∫ Q · f(θ) · sin θ dθ（Simpson 积分，400 步，积到 f 归零处）；Lambert 面光源 Φ = π · Q。
- ρ₁：首次反射面的反射率，取背景：白 0.82、灰 0.18、黑 0.035。
- A_总：房间所有表面面积。场景为 20 × 18 m、6 m 高，A_总 = 1176 m²。
- ρ̄：面积加权平均反射率。无缝背景 244 m² 取 ρ₁，其余墙面和天花板与影棚同色，取 0.94·ρ₁。
- 系数 2：积分腔公式给出的是平面照度；球形测光表在均匀光场中的读数是平面照度的 2 倍（其响应在整个球面上积分为 2π，平面余弦接收为 π）。

这是全棚平均值，不是逐点光照传递：不反映人物离背景远近、反弹方向和局部颜色，只用于估计整体补光量级，同时作为渲染中环境光的强度。大棚面积大，所以白棚里反弹光占比只有几个百分点；小棚会明显更多。

公式来源：积分球照度 E = Φ·ρ₁ / (A·(1 − ρ̄))（Labsphere 积分球理论）。

---

## 7. 总曝光、读数与光比

- 总曝光：H_总 = Σ 各灯直射 H + H_反射。
- 读数：N = √(H_总 · S / C)，与相机设置的偏差 Δ = log₂(H_总 / H_目标) 档。
- 每盏灯的贡献比例：Hᵢ / H_总。
- 光比：直射贡献最大的两盏灯之比 H₁ / H₂，并换算成档数。

## 8. 颜色

### 8.1 色温 → 色度坐标

Kim 等（2002）的普朗克轨迹三次样条拟合，适用 1667–25 000 K。

x_c：

- 1667–4000 K：−0.2661239·10⁹/T³ − 0.2343589·10⁶/T² + 0.8776956·10³/T + 0.179910
- 4000–25 000 K：−3.0258469·10⁹/T³ + 2.1070379·10⁶/T² + 0.2226347·10³/T + 0.240390

y_c：

- 1667–2222 K：−1.1063814x³ − 1.34811020x² + 2.18555832x − 0.20219683
- 2222–4000 K：−0.9549476x³ − 1.37418593x² + 2.09137015x − 0.16748867
- 4000–25 000 K：3.0817580x³ − 5.87338670x² + 3.75112997x − 0.37001483

### 8.2 渲染颜色

取 Y = 1，X = x/y，Z = (1 − x − y)/y，用 IEC 61966-2-1（sRGB）矩阵转成线性 RGB：

  R = 3.2404542X − 1.5371385Y − 0.4985314Z
  G = −0.9692660X + 1.8760108Y + 0.0415560Z
  B = 0.0556434X − 0.2040259Y + 1.0572252Z

负值截为 0，不再把最大通道归一，所以亮度 Y 保持为 1：改变色温不会改变画面亮度，测光读数与画面一致。6504 K 黑体不等于 D65 白点，渲染出来略偏品红，这是正常的。

### 8.3 混合色温与 Duv

每盏灯的三刺激值按其照度曝光量加权相加，得到合成色度 (x, y)，换成 CIE 1960 uv。在普朗克轨迹上按 1 迈尔德间隔（1667–25 000 K）搜索最近点，再用黄金分割细化：

- 最近点的色温即相关色温 CCT，显示取整到 50 K；
- 到最近点的距离即 **Duv**，在轨迹上方（偏绿）为正，下方（偏品红）为负。

混合光会离开普朗克轨迹，只看色温会丢失信息，所以页面同时显示 Duv。灯具的色度在这里都假定落在普朗克轨迹上；真实 LED 的 Duv、光谱尖峰和相机同色异谱没有建模。

## 9. 景深虚化（机位视角）

### 9.1 弥散圆（薄透镜模型）

对焦在距离 s 时，距离 D 处的一点在传感器上的弥散圆直径：

  **c = f² · |1 − D/s| / (N · D · (1 − f/s))**

- f 焦距，N 光圈，s、D 均以 mm 计，D 为沿视线方向的深度。
- 对焦无限远时 c = f² / (N · D)。
- 换算成像素：画面高度对应全画幅传感器的 24 mm。模糊半径上限为画面高度的 4%（且不超过 40 像素），极浅景深时远处背景的虚化会比真实的弱。

### 9.2 清晰范围与超焦距

允许弥散圆 c₀ = 0.03 mm：

- 超焦距 **H = f² / (N · c₀) + f**
- 对焦在 s 时：近点 **s(H − f) / (H + s − 2f)**，远点 **s(H − f) / (H − s)**，s ≥ H 时为无限远
- 对焦无限远时：近点 **H − f**（由 f²/(N·D) ≤ c₀ 得出），远点为无限远

例：50 mm、f/8 时 H = 10.47 m，对焦无限远的近点为 10.42 m。

对焦距离不小于焦距，也不小于 max(0.25 m, 8 × 焦距)，作为常见镜头的最近对焦距离近似。真实镜头还涉及入瞳出瞳、近摄有效光圈和像差，薄透镜模型不包含这些。

### 9.3 模糊的实现

单通道“散射转聚集”（Gustafsson 2018）：每个像素在黄金角螺旋上取样，相当于圆形光圈；样本自身的弥散圆覆盖到当前像素时才计入；位于后方的样本半径限制在当前像素弥散圆的 2 倍以内，防止清晰前景被背景吞掉。计算在线性 HDR 空间进行，再用与成片相同的 AgX 色调映射输出。单张深度图缺少被前景挡住的背景信息，前景边缘的虚化是视觉近似。

### 9.4 对焦方式

默认对焦脸部；可拖动对焦距离（对数刻度，下限见 9.2，上限 32 m）、点“无限远 ∞”，或在机位视角双击画面对焦到该处。

## 10. 画面视图与直方图

曝光判断以测光中灰 = 0.18（场景线性值）为基准，ev = log₂(L / 0.18)，L = 0.2126R + 0.7152G + 0.0722B。

| 视图 | 规则 |
| --- | --- |
| 成片 | AgX 色调映射后的画面 |
| 伪色 | 按 ev 分档上色，±⅓ 档为绿色，≥ +2.5 档为红色 |
| 斑马纹 | +2 ~ +2.5 档叠加斜条纹，≥ +2.5 档标红 |
| 溢出 | ≥ +2.5 档标红，≤ −5 档标蓝，其余为灰度图 |

+2.5 档和 −5 档是参考阈值。相机实际在哪里饱和，取决于机型、ISO 和各通道；暗部能否恢复取决于噪声和黑电平。

**直方图**统计的是显示画面（色调映射之后、8 位），每 4 个像素取 1 个，共 256 档：亮度 Y = round(0.2126R + 0.7152G + 0.0722B)，RGB 三条分别统计。“画面高光占比”是任一通道 ≥ 254 的像素比例，“画面纯黑占比”是 Y ≤ 1 的像素比例。它们描述显示画面，不等于 RAW 传感器溢出。纵轴按 1–254 档中的最大值归一。
