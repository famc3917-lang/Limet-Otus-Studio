# 观隅鸮馆 · 错误与提示参考

本文列出软件可能显示的全部错误与拒绝提示，按下列领域分组。每条给出服务返回的 HTTP 状态码（如有）、提示的含义和解决办法。

使用方法：

- 在本页搜索你看到的提示文字。界面会按所选语言显示提示，中英文两份参考的条目完全对应。
- `{1}`、`{2}` 表示运行时填入的内容，例如字段名、数字或权限名称。
- 带状态码的提示来自服务端；没有状态码的提示由软件界面或桌面端直接给出。
- 如果提示不在本页，或按解决办法处理后仍然出现，请记下发生时间、操作步骤和完整提示后反馈。

## HTTP 状态码

| 状态码 | 含义与处理 |
| --- | --- |
| 400 | 请求内容不符合要求，例如必填项为空、格式错误或数值超出范围。按提示修改后重新提交。 |
| 401 | 没有登录、登录已过期，或 API 密钥无效。重新登录，或更换有效的 API 密钥。 |
| 403 | 已识别身份，但没有执行该操作的权限，或请求来源不受信任。请超级管理员分配权限，或从正确的网址访问。 |
| 404 | 请求的记录或接口不存在，可能已被删除或清理。刷新后核对。 |
| 405 | 接口不支持这种请求方法。按接口手册使用正确的方法。 |
| 409 | 数据在此期间被其他人修改，或操作与当前状态冲突。刷新读取最新数据，核对后再操作。 |
| 413 | 请求内容过大。缩小上传内容后重试。 |
| 426 | 对接软件使用的协议版本不兼容。升级对接方。 |
| 429 | 请求过于频繁，或语音处理正忙。稍等片刻后重试。 |
| 500 | 服务器内部错误。稍后重试；反复出现时请查看服务器日志或反馈。 |
| 503 | 服务暂不可用，通常是服务器配置不完整、组件未安装或正在重启。由部署负责人检查配置，或按提示安装组件。 |
