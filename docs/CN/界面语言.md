# 界面语言

注册页面和工作室偏好提供中文、英文选项。语言选择保存在当前设备；桌面菜单与窗口标题使用相同语言。

切换语言仅改变界面及内置说明。客户姓名、用户备注、自定义套餐、音色名称和其他业务输入保持原文。语音音色决定朗读语言与助手身份，界面语言不会更换音色。

订单与经营概览继续使用工作室币种。切换界面语言不会换算金额或更改币种标记；不同币种之间没有自动汇率换算。

助手请求可携带 language 字段，取值为 zh 或 en。服务端校验后，仅用于当前轮回复语言和天气说明，不改变权限或所选音色。省略该字段时使用中文；历史对话保留原文。

## 打印模板

中文与英文分别保存预定单、订单确认单和付款汇总模板。英文首次使用时加载英文默认内容，中文原有模板继续保留。切换语言不会翻译或覆盖已保存的自定义条款；同一页面内未保存的草稿按语言保留，离开页面前请保存。恢复原文只重置当前语言模板，保存后生效。打印金额使用工作室币种，不随模板语言换算。

操作说明使用中英文 FTS5 关键词检索，英文对话返回英文条目。索引只包含内置软件说明，不加载神经检索模型；实际工具定义仍按每轮能力提供。
