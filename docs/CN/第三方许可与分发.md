## Electron 与 Chromium

当前工程锁定 Electron 44.0.0。Electron 的 MIT 许可证与 Chromium 第三方许可声明分别保存在 [Electron LICENSE](../../third-party/notices/electron/LICENSE) 和 [完整第三方声明](../../third-party/notices/electron/LICENSES.chromium.html)。相关组件的原始声明同时提供为 [FFmpeg](../../third-party/notices/electron/ffmpeg.txt) 与 [WebKit / Blink](../../third-party/notices/electron/WebKit.txt)。这些声明完整保留上游文本，不以摘录替代。

上游总清单包含多个平台的资料，不表示每个条目都进入当前 Windows 产物。发布审核须以实际分发文件、链接关系、构建版本及对应源码为准，不能只扫描 npm 包的 license 字段或统计许可证关键词。

### FFmpeg 对应源码

Electron 44.0.0 基于 Chromium 152.0.7977.54。安装目录中的 `ffmpeg.dll` 是 Chromium 构建的 FFmpeg，以 LGPL 分发，通过动态链接加载，可以用兼容的自行构建版本替换。对应源码为该 Chromium 版本 [DEPS](https://chromium.googlesource.com/chromium/src/+/refs/tags/152.0.7977.54/DEPS) 中固定的 [chromium/third_party/ffmpeg](https://chromium.googlesource.com/chromium/third_party/ffmpeg) 修订，Electron 的构建配置见 [electron v44.0.0](https://github.com/electron/electron/tree/v44.0.0)。

| SenseVoiceSmall INT8 | 语音识别模型 | FunASR Model Open Source License 1.1 | `speech/FunASR-MODEL-LICENSE.txt` |
| CosyVoice（代码） | 语音合成引擎 | Apache-2.0 | `tts/vendor/CosyVoice/LICENSE` |
| Matcha-TTS（代码） | 语音合成组件 | MIT | `tts/vendor/CosyVoice/third_party/Matcha-TTS/LICENSE` |
| CosyVoice-300M-SFT | 语音合成模型 | Apache-2.0 | 模型仓库 FunAudioLLM/CosyVoice-300M-SFT |
